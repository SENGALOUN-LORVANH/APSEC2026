| 15 | 2026-09-25 | **Fail-fast on credit/billing exhaustion + pre-run balance check (engineering fix, NOT a methodology change).** The first full-run pass (2026-09-23) exhausted the API credit partway; `semantic.run_semantic` swallows a per-run billing error into a null-score result, so the semantic *stage* still looked "ok" and `run_full` marked the patch `complete` and kept going — writing **580 empty checkpoints** (521 credit-failed semantic + 59 genuine apply-failures).
